# OfflineAudio — Нейро-стенографист

Android-приложение для локального распознавания русской речи без подключения к интернету.

## Реализовано
- Импорт WAV-файлов.
- Распознавание речи на устройстве с помощью whisper.cpp и Whisper Tiny.
- Отображение стенограммы с временными метками.
- Экспорт стенограммы в TXT и JSON.
- Работа без облачных API.

## Проверенное устройство
ZTE 2050RU, Android 9 (API 28), ARM64.

## Поддерживаемый аудиоформат
WAV, PCM 16-bit, mono, 16000 Hz.

## Использование
1. Установить APK на Android.
2. Открыть OfflineAudio.
3. Выбрать WAV-файл.
4. Нажать «Обработать аудио».
5. Дождаться расшифровки.
6. Сохранить результат в TXT или JSON.

## Сборка
Открыть проект в Android Studio, дождаться Gradle Sync
и выполнить Build > Build APK(s).

Исходники whisper.cpp находятся в third_party/whisper.cpp.
Модель Whisper Tiny включена в assets приложения.

## Известные ограничения
- Автоматическая диаризация говорящих пока не реализована.
- Поле speaker_id в JSON содержит null.
- Локальная LLM пока не интегрирована.
- Поддерживается только WAV PCM 16 кГц, моно.
- На слабых устройствах распознавание может занимать несколько минут.

## Тестирование
Проверена локальная расшифровка тестового WAV на ZTE 2050RU.
Результат: «Приветствую. Привет.»
Проверен экспорт JSON с временными метками.

## Используемые технологии
Kotlin, Jetpack Compose, whisper.cpp, Whisper Tiny.
